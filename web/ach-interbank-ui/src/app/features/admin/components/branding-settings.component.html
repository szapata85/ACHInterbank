Identidad visual

Personaliza los logos, fondos y botones de la aplicación para el acceso público y el portal autenticado. Las imágenes pueden ser PNG o SVG, y los colores aceptan cualquier valor compatible con CSS (hexadecimal, rgb, degradados).

Requisitos sugeridos para el logo

  • Formato PNG o SVG con fondo transparente.
  • Dimensiones recomendadas: 240 × 80 px (proporción 3:1) para verse nítido en los encabezados.
  • Peso máximo sugerido: 300 KB.
