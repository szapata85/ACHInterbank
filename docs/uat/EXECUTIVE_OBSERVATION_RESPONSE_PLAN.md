# Plan respuesta observaciones ejecutivas - Fase 6D.10

Productivo permanece NO-GO. Las observaciones no equivalen a aprobacion ni habilitan carga tecnica.

## Tipos de observacion

- Seguridad.
- Compliance.
- Tecnologia.
- Operaciones.
- Comite.
- Terceros ACH/CENIT.

## Severidades

| Severidad | Criterio |
| --- | --- |
| Critica | Bloquea avance por riesgo financiero, seguridad, privacidad o NO-GO. |
| Alta | Bloquea UAT externo hasta cierre o aceptacion formal. |
| Media | Requiere accion antes de ejecutar fase posterior. |
| Baja | Ajuste documental o evidencia complementaria. |
| Observacion | Comentario sin bloqueo inmediato. |

## Estados

| Estado | Uso |
| --- | --- |
| Recibida | Observacion registrada. |
| En analisis | Responsable evalua accion e impacto. |
| En correccion | Accion en curso. |
| Respondida | Respuesta enviada. |
| Validada | Cierre aceptado. |
| Diferida | Pasa a fase posterior o tercero. |
| Cerrada | Sin accion pendiente. |

## Flujo atencion

1. Registrar observacion, origen, severidad y responsable.
2. Evaluar si bloquea NO-GO, SOAP real, datos reales, secretos o certificados/endpoints.
3. Definir accion y evidencia esperada.
4. Actualizar matriz post-comite.
5. Presentar respuesta sanitizada.
6. Validar cierre o diferimiento formal.

## Evidencia requerida

- Respuesta escrita.
- Anexo o documento actualizado.
- Evidencia sanitizada.
- Responsable y fecha de validacion.
- Estado final.

## Responsable

La Mesa UAT consolida; cada area responde por observaciones de su dominio. Observaciones de terceros no se cierran con evidencia interna.
