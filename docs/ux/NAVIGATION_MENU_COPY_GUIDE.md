# Guía de copy humanizado — NAV-MENU-IA-001

## Regla principal

El menú debe decir **qué hará o encontrará el usuario**, no cómo está implementado.

## Acrónimos permitidos

`ACH` y `NACHA-M` pueden mantenerse cuando aclaran el dominio. Evitar exponer `CFA`, `MFT`, `SOAP`, `UAT` en navegación funcional.

## Alcance

Aplicar al menú y luego a `title`, `breadcrumb`, encabezados y tarjetas principales. No renombrar clases, rutas ni contratos técnicos sólo por copy.
