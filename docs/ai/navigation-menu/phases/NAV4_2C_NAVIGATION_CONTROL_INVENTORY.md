## Colecciones dinámicas revisadas

- **Reportes:** el único control genérico `Abrir reporte` se alimenta de 10 cards ya canonicalizadas; no se cambió route, orden, cardinalidad ni contenido funcional.
- **Catálogos:** el control genérico se alimenta de ocho accesos; siete ya estaban alineados y `Códigos de transacción ACH` se corrigió a `Códigos de transacción`.
- **CENIT:** los dos controles genéricos `Abrir consulta` apuntan a rutas contextuales/non-menu; se conservaron.
- **MainLayout:** los links de menú consumen directamente `item.label` del árbol backend. No se añadió catálogo paralelo.
- **`ui-migas-pan`:** el componente es genérico y conserva los labels que recibe; sus usos se inspeccionaron y no requirieron una taxonomía nueva.

## Acciones funcionales explícitamente fuera de alcance

Las seis definiciones detectadas que combinan operación funcional con navegación se dejaron sin cambios: `Nueva reclamación` (dialog/creación), `Actualizar información`, `Limpiar filtros`, `Guardar perfiles`, `Clonar` mapping y `Crear borrador`. Además se preservaron acciones funcionales encontradas durante la revisión como `Enviar archivo`, `Descargar`, `Reintentar`, `Reprocesar`, `Archivar`, `Retirar archivo`, `Validar` y otras mutaciones de dominio.

## Accesibilidad focal

Sólo se cambió copy accesible asociado al mismo control corregido: el retorno compartido a `/clearing-houses` ahora usa visible label, `aria-label` y `matTooltip` coherentes con `Volver a Cámaras compensadoras`. No se ejecutó auditoría ARIA general.

## Source of truth

NAV4.2C no crea un mapa route→label. `NavigationNamingService` **no fue modificado ni inyectado en nuevos componentes**: los controles focales están acoplados a un único destino concreto o ya tenían colecciones locales de navegación; en esos casos se ajustó únicamente el string local existente. MainLayout continúa reutilizando labels backend. El backend sigue siendo source of truth para titles/breadcrumbs; estos strings locales son copy de CTAs concretos y no una taxonomía global.
