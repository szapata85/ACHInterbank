# NAV4.2G — Inventario de mensajes y estados vacíos

Estado: `IMPLEMENTED_UNVERIFIED_ENVIRONMENT`

Baseline: `NAV4.2F`. Alcance: exclusivamente copy/display de feedback y estado generado por la SPA. No se inventaría ni modifica `mat-error`, validadores, confirmaciones, tooltips/ARIA generales, labels/placeholders/hints, acciones, headings, columnas, navegación, permisos, seed, DTOs/endpoints/payloads o backend.

## Decisiones de fase

- `DEC-NAV-4.2G-001`: el copy `SPA_AUTHORED` puede humanizarse; `BACKEND_PASSTHROUGH` y `EXTERNAL_PASSTHROUGH` se preservan sin traducir, resumir, corregir, ocultar códigos ni cambiar causales. En `HYBRID` sólo es elegible el wrapper SPA; el fragmento externo permanece intacto.
- `DEC-NAV-4.2G-002`: los estados vacíos representan estados distintos (lista vacía, búsqueda/filtro sin coincidencias, carga pendiente, ausencia de configuración, historial vacío, ausencia legítima, error, no aplicable); no se unifican bajo un mensaje genérico.
- `DEC-NAV-4.2G-003`: `mat-error` y validaciones quedan fuera de NAV4.2G y reservados para `NAV4.2H — mensajes de validación`.

## Controles semánticos específicos

- Integraciones: `preview-change` sigue siendo sólo previsualización/confirmación; ningún mensaje nuevo afirma ejecución SOAP ni conectividad probada.
- MFT: sólo el `test-connection` real conserva la afirmación de conexión exitosa; guardar configuración no se presenta como prueba de conectividad.
- Bulk ingestion: lote registrado, reintento solicitado y cancelación registrada permanecen diferenciados de procesamiento terminado.
- NACHA-M: los mensajes de carga/ingesta y los mensajes de procesamiento se mantienen separados; `.xls/.xlsm` no se modifica en esta fase.
- Returns/ROR: la generación local de archivo no se presenta como transmisión externa.
- Cifrado/descifrado: sólo operaciones que terminan en el servicio correspondiente usan “archivo cifrado” o “archivo descifrado”.

## Fuera de alcance restante

`NAV4.2H` conserva `mat-error` y mensajes de validación. Confirmaciones y tooltips/ARIA generales permanecen para incrementos separados; NAV4.2H no fue ejecutado por esta fase.
