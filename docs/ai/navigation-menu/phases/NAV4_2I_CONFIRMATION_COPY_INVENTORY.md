## Decisiones durables

- **DEC-NAV-4.2I-001:** La confirmación expresa sólo acción y consecuencia demostrables.
- **DEC-NAV-4.2I-002:** Sólo título/cuerpo pueden cambiar; botones, handlers y resultado son invariantes.
- **DEC-NAV-4.2I-003:** Backend/external passthrough no se reescribe.

## No alcance / restante

Quedan fuera de NAV4.2I tooltips/ARIA generales. Las validaciones NAV4.2H, feedback NAV4.2G, tablas NAV4.2F, fields NAV4.2E, actions NAV4.2D y navegación/seguridad/seed permanecen sin cambios. El `beforeunload` se registra como `OUT_OF_SCOPE` porque el navegador controla su mensaje.
