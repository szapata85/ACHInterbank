# Micro-prompts P1 — CFA-SOAP-UX-MAP-001

Ejecutar un solo bloque por turno.

## P1.1 — Modelo de ContractVersion

```text
Lee P1, `DATA_MODEL_AND_MIGRATIONS.md` y las secciones de entidades de `SOAP_CONTRACT_MAPPING_ARCHITECTURE.md`. Implementa solo el modelo/EF configuration aditivo de `IntegrationContractVersion`, metadata de parámetros y vínculos requeridos, sin cambiar runtime. Conserva IDs/compatibilidad. Agrega tests de invariantes de dominio/configuración si aplican. Actualiza estado; siguiente `P1.2`.
```

## P1.2 — Migraciones dual-provider y backfill

```text
Sobre P1.1, crea migraciones PostgreSQL y SQL Server para el modelo versionado. Implementa baseline contract versions para los tres métodos y backfill que preserve parámetros, reglas y mappings existentes. No cambies runtime. Valida migración limpia/upgrade si el entorno lo permite; si no, registra NOT_RUN_ENVIRONMENT. Siguiente `P1.3`.
```

## P1.3 — Queries, constraints e inmutabilidad

```text
Implementa consultas por ContractVersion, unicidad/revision/only-one-active e inmutabilidad de Active/Retired según P1. Agrega pruebas focales de constraints y preservación exacta de los siete parámetros de RegistrarRespuesta. No introduzcas WSDL todavía. Siguiente `P1.4`.
```

## P1.4 — Cierre P1

```text
Ejecuta tests focales P1 y revisión de migraciones. Verifica que runtime siga usando legacy y que no cambió XML. Actualiza decisiones/gaps/evidencia, marca P1 DONE y fija `active_phase=P2`, `next_micro_prompt=P2.1` solo si ambas migraciones y backfill quedan coherentes.
```
