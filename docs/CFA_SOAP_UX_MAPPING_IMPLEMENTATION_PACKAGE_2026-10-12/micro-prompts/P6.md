# Micro-prompts P6 — CFA-SOAP-UX-MAP-001

Ejecutar un solo bloque por turno.

## P6.1 — Read model y lista de datos CFA

```text
Lee P6 y `API_CONTRACTS.md` workspace de mapping. Implementa vista `Relación de información`: lista por nombres funcionales, estado completo/pendiente/inválido/no aplica, búsqueda/filtros y resumen de cobertura. Detalle técnico colapsado. Siguiente `P6.2`.
```

## P6.2 — Selector de origen y tratamiento

```text
Implementa edición por parámetro con Reactive Forms tipados: selector de origen agrupado/buscable desde metadata backend y tratamientos compatibles provistos por servidor. Nada de field paths libres ni catálogos duplicados en Angular. Guardado con Revision. Siguiente `P6.3`.
```

## P6.3 — Vista previa y validación humanizada

```text
Implementa preview por campo y validación general mostrando lenguaje funcional: dato requerido, origen, tratamiento, valor resultante sanitizado. Errores backend se traducen a mensajes útiles sin ocultar detalle técnico para soporte. No exponer PII completa. Siguiente `P6.4`.
```

## P6.4 — Concurrencia, publicación y cierre P6

```text
Implementa UX de conflicto de Revision y diálogo de publicación humanizado. Publicar debe estar deshabilitado con required pendientes. Agrega Harness/keyboard/form tests focales. Verifica el escenario de campo nuevo como “1 dato nuevo pendiente”. Cierra P6 y sigue `P7.1`.
```
