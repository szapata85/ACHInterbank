# Micro-prompts P4 — CFA-SOAP-UX-MAP-001

Ejecutar un solo bloque por turno.

## P4.1 — Servicios de versiones y diff

```text
Lee P4, `API_CONTRACTS.md` secciones contract/diff y `SOAP_CONTRACT_MAPPING_ARCHITECTURE.md` versionado. Implementa query/command de crear/clonar/versionar, metadata funcional y diff `MappingRequired/RequiresDevelopment`. Sin WSDL import aún. Tests focales. Siguiente `P4.2`.
```

## P4.2 — Análisis/importación WSDL segura

```text
Implementa analyze/import local de WSDL/XSD con DTD/XXE deshabilitado, sin red, límite de tamaño, hash SHA-256 y bloqueo de estructuras no soportadas. No activar automáticamente. Agrega fixtures adversariales de `TESTING_AND_RELEASE_GATES.md` sección 5. Siguiente `P4.3`.
```

## P4.3 — Clonación de mapping entre contratos

```text
Implementa clone mapping v1→v2 por `ParameterPath` compatible y clasificación de copied/new/removed/incompatible. Un campo required nuevo debe dejar el draft incompleto. Agrega validación contract+mapping. Siguiente `P4.4`.
```

## P4.4 — Activación atómica y rollback

```text
Implementa activación fail-closed: ContractVersion + MappingSet compatible/completo, concurrencia por Revision, auditoría e inmutabilidad. Implementa rollback a versión previa compatible sin mutar historial. Tests de conflicto/incompleto/rollback. Siguiente `P4.5`.
```

## P4.5 — Prueba no-code y cierre P4

```text
Ejecuta el escenario obligatorio `TIPOCLIENTE_TEST` solo en tests: v2 + campo scalar required + clone mapping + falla pendiente + map a fuente existente + valida + genera XML + rollback. Demuestra que writer y clientes SOAP no cambiaron para añadir ese campo. Elimina cualquier seed ficticio productivo. Cierra P4 y sigue `P5.1`.
```
