# Micro-prompts P8 — CFA-SOAP-UX-MAP-001

Ejecutar un solo bloque por turno.

## P8.1 — Prueba de ausencia de callers legacy

```text
Lee P8. Busca callers reales de typed mappers, bootstrap hardcoded de parámetros y componentes SPA reemplazados. No borres nada aún. Produce lista keep/remove con evidencia y tests que protejan runtime nuevo. Siguiente `P8.2`.
```

## P8.2 — Retiro controlado de legacy

```text
Elimina únicamente legacy sin callers y respaldado por P8.1. Retira autoridad hardcoded de parámetros y componentes reemplazados, conservando redirects necesarios. No elimines parsers específicos ni controles funcionales. Build/tests focales. Siguiente `P8.3`.
```

## P8.3 — Gauntlet técnico y UX

```text
Ejecuta el gauntlet P8: parameter/XML injection, XXE, required/type mismatch, cross-method/version mapping, concurrencia, activación incompleta, rollback, orden, output-as-input, mobile overflow, keyboard trap, contraste y lenguaje técnico primario. Corrige defectos confirmados con regresión determinista. Siguiente `P8.4`.
```

## P8.4 — Cierre global

```text
Ejecuta gates completos disponibles backend/frontend/migraciones/paridad/no-code scenario. Revisa secretos, diff, docs y memoria. Marca `program_status=COMPLETE`, `next_micro_prompt=NONE`, `NEXT_ALLOWED_PHASE=NONE` solo con evidencia suficiente; lo no ejecutable queda NOT_RUN_ENVIRONMENT y puede impedir niveles de certificación correspondientes. Entrega cierre compacto.
```
